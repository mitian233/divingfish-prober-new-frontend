## 二、UI/交互差异

### 1. 表格显示

| 原版 | V3 |
|------|-----|
| Vuetify v-data-table (分页、排序内置) | TanStack DataTable（已接入分页、排序、列显隐） |
| 移动端全屏对话框 | 响应式对话框，无特殊移动端处理 |
| Material Design风格 | Tailwind CSS + shadcn风格 |

### 2. 对话框

| 原版 | V3 |
|------|-----|
| v-dialog 组件 | shadcn Dialog组件 |
| 全屏模式(移动端) | 固定宽度，响应式 |
| v-card 嵌套 | Card组件 |

### 3. 消息提示

| 原版 | V3 |
|------|-----|
| v-message (Vuetify) | sonner (toast) |

## 三、API/数据流差异

### 1. 状态管理

| 原版 | V3 |
|------|-----|
| Vue 2 data/computed | Pinia Store |
| Vue.set 手动响应式 | Vue 3 自动响应式 |
| 组件内直接调用axios | Service层封装 |

### 3. 接口容错与开发联调

| 项目 | V3状态 | 说明 |
|------|--------|------|
| `/api` 本地代理 | ✅ 已实现 | 支持通过 `VITE_API_PROXY_TARGET` 配置代理目标 |
| HTML 响应拦截 | ✅ 已实现 | 当接口误返回 `index.html` 时在 API 层拦截并提示，不再污染业务数据 |
| 服务层响应校验 | ✅ 已实现 | 舞萌/中二关键接口增加运行时结构校验，避免 setup 阶段崩溃 |

### 2. 数据导入

| 原版 | V3 |
|------|-----|
| xmldom + xpath 解析HTML | DOMParser 解析HTML |
| 正则匹配diff图标 | 同样使用正则 |

## 五、技术债务

1. **测试覆盖不足**: 关键 domain/store/流程缺少单元与集成测试
2. **ECharts体积较大**: 已改为按需加载，后续可继续做 manualChunks 优化
3. **移动端适配**: 对话框和表格需要更好的移动端体验
4. **类型完善**: 部分类型定义需要补充（如 chart_stats/chuni music 字段）
5. **接口联调风险**: 辅助模块依赖后端跨域与鉴权，需实际联调验证
